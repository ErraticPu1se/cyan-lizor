# Security Policy

## Supported Versions

Security fixes target the latest published Lizor Windows preview. Please update before reporting an issue. Older releases do not receive separate security patches.

| Version | Supported |
| ------- | --------- |
| 0.2.1-preview.1 (current) | Yes |
| Older releases | No |

Development branches are experimental and are not supported releases. Security reports about them are still welcome; include the branch and commit.

## Reporting a Vulnerability

Use GitHub's **[Report a vulnerability](https://github.com/ErraticPu1se/cyan-lizor/security/advisories/new)** form to report a suspected security issue privately to the maintainers.

Do not post vulnerabilities, exploit details, credentials, or private data in public issues or discussions.

Please include:

- Lizor version, or the branch and commit if testing development code.
- Windows version and relevant configuration.
- Steps to reproduce the issue and its possible security impact.
- Relevant logs or a minimal demonstration, with personal information and secrets removed. Do not upload Rain World game files.

This is an independently maintained project. Reports are reviewed as time permits; there is no guaranteed response or fix deadline. Follow-up questions and progress updates will be shared through the private report. Confirmed issues will be assessed for a fix in the latest supported release. If a report cannot be reproduced or is not considered a vulnerability, the maintainer will explain the outcome there.

Please coordinate public disclosure with the maintainer so users have an opportunity to update.

Ordinary bugs, such as unusual movement or performance problems, belong in [GitHub Issues](https://github.com/ErraticPu1se/cyan-lizor/issues). If you suspect a security impact, use private reporting instead.

## Official Downloads

Download packaged builds from the project's [GitHub Releases](https://github.com/ErraticPu1se/cyan-lizor/releases). Third-party repackaged builds are not maintained by this project.
